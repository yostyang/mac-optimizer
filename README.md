# Mac 一键优化

**不用重启，也能排查卡顿、查看状态和管理日常工具。** · [介绍页](https://yostyang.github.io/mac-optimizer/) · [下载 v2.1](https://github.com/yostyang/mac-optimizer/releases/tag/v2.1)

纯 Swift + SwiftUI/AppKit 菜单栏应用，支持 macOS 13 及以上，提供 Apple 芯片与 Intel 通用版。

## 功能

- **一键体检**：分析内存压力、CPU、Spotlight、后台虚拟机与高占用应用，给出结论和处理入口；退出应用前由你确认。
- **菜单栏与实时监控**：CPU/GPU、温度、内存、磁盘、网速、风扇、电池和外设电量；面板根据内容和屏幕高度调整，提供截图、麦克风、常亮、擦屏、充电上限等快捷操作。
- **接显示器模式**：插电并连接外接显示器时阻止闲置睡眠，允许屏幕熄灭与手动睡眠；不修改 pmset，退出应用会释放断言。
- **电池与充电**：健康度、循环次数、电压、电流、充放电功率、预计充满时间与应用能耗；可设置充电上限或临时充到 100%。读不到的充电器实时输入和系统功耗会明确标注。
- **网络诊断与测速**：延迟、丢包、DNS、VPN/TUN 下 TCP 连通性佐证，手动下载/上传测速、Wi-Fi 与公网信息。总速率历史可保留 30 天；按应用显示的是联网连接数，不是应用字节流量。
- **清理预览**：缓存、日志、安装包、开发构建产物及下载目录大文件。先扫描、勾选、确认，再移到废纸篓；提供白名单与操作记录。残留路径用于人工核对，不提供全盘自动残留识别。
- **改动与提醒**：集中查看 DNS 与清理记录；可选 CPU、磁盘和电池异常提醒，默认关闭。自动整理只准备清单，移动文件仍需确认。
- **显示器与蓝牙**：支持的设备可使用 DDC/CI 调节、显示场景与分辨率切换，并查看蓝牙设备电量。

基础监控无需安装特权助手；充电控制和 DNS 修改需要授权后台助手。清理项目可从废纸篓手动放回，DNS 有备份时可恢复原设置。

## 安装

到 [Releases](https://github.com/yostyang/mac-optimizer/releases/latest) 下载 `Mac-Optimizer-2.1.dmg`，打开后把 App 拖进「应用程序」。

应用未经过苹果公证。首次打开若提示“无法验证开发者”，到 **系统设置 › 隐私与安全性**，点击「仍要打开」；也可运行：

```bash
xattr -dr com.apple.quarantine "/Applications/Mac一键优化.app"
```

## 当前限制

- 某些外接显示器的充电助手检测不完整，不能保证“连接外接显示器时自动暂停充电上限”在所有设备生效。
- 测速受端点、VPN 与网络环境影响；当前提供整次传输平均速度，未提供逐秒实测曲线或负载中延迟。
- 30 天流量历史仅包含网络页开启采样期间的总接口速率；按应用一栏为连接数。
- 接显示器模式的断言行为有测试覆盖；熄屏后 VPN 持续连接仍取决于具体 VPN 和网络环境。

## 从源码构建

需要 Xcode 命令行工具，无需 Xcode 工程：

```bash
./build.sh
./test.sh
```

`build/` 生成通用 App 和 DMG；`build-test/summary.txt` 保存逻辑、界面与截图检查结果。截图先查看，再决定是否更新 `goldens/`。

构建优先使用本机固定签名证书，没有时使用临时签名。`helper-cache/` 复用已签名的同一份充电助手，避免无必要的重新授权；证书、密码和助手缓存不提交仓库。
