# Mac 一键优化

一个轻量的原生 macOS 小工具（SwiftUI），一键找出让 Mac 变卡的原因并处理。

## 功能

- **一键体检**：给出健康分，列出发现的问题，勾选后一键优化
- **资源占用排行**：按应用汇总内存 / CPU，一键退出
- **开机启动项管理**：禁止不需要的应用开机自启
- **浏览器管理**：同时开多个浏览器时快速退出多余的
- **Spotlight 修复**：索引进程卡住时一键重启
- **后台虚拟机**：发现 Claude 桌面版等应用的虚拟机占用
- **网络与 VPN**：检测多个 VPN 同时运行
- **显示性能优化**：减少透明度和动态效果，减轻大屏渲染负担

所有操作都需要你手动勾选或点击，不会自动关闭任何东西，也不需要管理员密码。

## 安装

到 [Releases](../../releases) 下载 `Mac一键优化.dmg`，打开后把 App 拖进「应用程序」。

应用没有经过苹果公证，第一次打开时如果提示“无法验证开发者”，请到 **系统设置 › 隐私与安全性**，在底部点「仍要打开」；或在终端运行：

```bash
xattr -dr com.apple.quarantine "/Applications/Mac一键优化.app"
```

支持 macOS 13 及以上，Apple 芯片和 Intel 均可。

## 从源码构建

需要 Xcode 命令行工具：

```bash
./build.sh
```
