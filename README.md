# Mac 一键优化

**不用重启，也能排查卡顿、查看状态和管理日常工具。** · [介绍页](https://yostyang.github.io/mac-optimizer/) · [下载正式版](https://github.com/yostyang/mac-optimizer/releases/latest)

纯 Swift + SwiftUI/AppKit 菜单栏应用，支持 macOS 13 及以上，提供 Apple 芯片与 Intel 通用版。

当前代码版本为 **2.10.0（31，待发布）**：桌面分区支持自定义比例和按住 ⇧ 拖动窗口到分区，清理记录可一键恢复。2.9.2 升级后会核对实际运行的充电助手，旧助手仍在运行时自动切换到新版，并保留原来的充电设置。2.9.1 保留了扩展坞供电保护和保存失败反馈。安装包见 [最新 Release](https://github.com/yostyang/mac-optimizer/releases/latest)。

范围与验收记录：[第零期](docs/phase-zero-safety.md) · [第一期](docs/phase-one-monitor.md) · [第二期](docs/phase-two-summary.md)。后续体验、电池、显示器、Keychron 与分屏安排见 [待办优先级](docs/BACKLOG.md)。

2.4 补齐按应用真实网络字节、后台流量历史、系统测速、网络卡片、TUN 去重与应用卸载；验收和范围见 [2.4 说明](docs/2.4-network-uninstall.md)。2.4.1 修复了重新启动后恢复已开启的「常亮」。

## 功能

- **桌面分区（2.6）**：每块屏幕选 1:2:1 / 平分 / 2/3+1/3 模板，⌘K「放到左区/中区/右区」「撤销归位」；需辅助功能权限。

- **一键体检**：分析内存压力、CPU、Spotlight、后台虚拟机与高占用应用，给出结论和处理入口；退出应用前由你确认。
- **菜单栏与实时监控**：CPU/GPU、温度、内存、磁盘、网速、风扇、电池和外设电量；面板根据内容和屏幕高度调整，提供截图、麦克风、常亮、擦屏、充电上限、接显示器等快捷操作。2.8 起面板为双列指标卡：每张卡右上角是状态标签（温度、内存压力、容量、网络类型），电池卡显示已连接外设的电量圆环，读不到电量的外设画虚线环、标为「未取得」，不显示 0%。实时监控使用三层指标卡，最小窗口自动采用紧凑布局。`↑↓` 选进程、`↵` 处理、`⌘K` 看更多。
- **搜索与键盘**：顶部搜索栏可搜页面、操作和进程（例如输入 `edge` 直接列出 Edge 的进程和「关闭标签页」）；`⌘K` 列出选中项的全部操作；`⌘1–9` 切换页面。按 `⌥Space` 可在任何地方唤起全局命令面板，直接执行「接显示器」「体检」「关 Chrome 标签」，快捷键可在「设置」里录制。全局热键用系统接口实现，不需要辅助功能权限。
- **接显示器模式**：插电并连接外接显示器时阻止闲置睡眠，允许屏幕熄灭与手动睡眠；不修改 pmset，退出应用会释放断言。
- **电池与充电**：健康度、循环次数、电压、电流、充放电功率、预计充满时间与应用能耗；可设置充电上限或临时充到 100%。读不到的充电器实时输入和系统功耗会明确标注。2.8 新增最近 30 分钟 / 2 小时的功率趋势（输入、充入、放电三条线分开画，断档与接电/拔电处留空，不拼线），应用能耗显示采样开始时间、覆盖时长、最新样本和缺口。
- **网络诊断与测速**：首屏展示接口、代理/VPN、DNS、外网 IP、延迟、上下行和已记录的流量；保留诊断详情、测速与流量标签。按应用显示真实字节，VPN 转发单列去重；历史使用滚动时段，缺记录不补零。公网 ICMP 与真实域名解析耗时分开显示。
- **清理预览与卸载**：缓存、日志、安装包、开发构建产物及下载目录大文件。先扫描、勾选、确认，再后台逐项移到废纸篓，失败项可重试。可选择应用后检查已知标准目录中的关联项，支持卸载记录恢复；不保证覆盖应用自行指定的所有目录。
- **改动与提醒**：集中查看 DNS 与清理记录；可选 CPU、磁盘和电池健康异常提醒，默认关闭，显示系统通知权限。开启后关闭窗口或菜单栏仍低频监测，通知可跳转相应页面。未接通的自动整理开关已移除。
- **显示器与蓝牙**：支持的设备可使用 DDC/CI 调节、显示场景与分辨率切换，并查看蓝牙设备电量。色彩模式分为系统 ICC、显示器硬件模式（VCP 0x14 / 0xDC）和软件色温三组；硬件模式按 MCCS 标准命名，未定义的值保留编号，可按显示器菜单为本机命名；切换后回读核对，失败给出重试与恢复。

进程处理会等待可观察的退出结果；未确认完成不计入完成统计。DNS 恢复读取状态核对后才结束，失败或超时保留待恢复记录。

基础监控无需安装特权助手；充电控制和 DNS 修改需要授权后台助手。2.9.2 会在每次启动时核对助手进程与当前安装文件，原地升级先等待旧助手自行重启，替换 App 时则自动注销并重新注册。清理项目可从废纸篓手动放回，DNS 有备份时可恢复原设置。

## 安装

到 [Releases](https://github.com/yostyang/mac-optimizer/releases/latest) 下载 `Mac-Optimizer-x.x.dmg`，打开后把 App 拖进「应用程序」。

应用未经过苹果公证。首次打开若提示“无法验证开发者”，到 **系统设置 › 隐私与安全性**，点击「仍要打开」；也可运行：

```bash
xattr -dr com.apple.quarantine "/Applications/Mac一键优化.app"
```

## 当前限制

- 某些外接显示器的充电助手检测不完整，不能保证“连接外接显示器时自动暂停充电上限”在所有设备生效。
- 测速受端点、VPN 与网络环境影响；系统未提供的指标显示未知，不能据单次结果判断持续故障。
- 流量历史只覆盖实际采样期间，网卡总量与可归属应用流量的口径不同；总览使用相同小时桶，缺少的时段不补零。
- 接显示器模式的断言行为有测试覆盖；熄屏后 VPN 持续连接仍取决于具体 VPN 和网络环境。
- 显示器硬件模式名称按 MCCS 标准推断，厂商可能挪作他用；以显示器菜单为准，可在色彩模式页为本机命名。
- 功率趋势只在本次运行期间记录（面板或电池页打开时每 10 秒，后台每 30 秒），重启后从头开始；应用能耗是按进程估算的处理器能耗，不是整机功率。
- Keychron K3 Pro 等经典蓝牙键盘目前取不到有效电量，显示「未取得」；型号专项验证见待办 K02。

## 从源码构建

需要 Xcode 命令行工具，无需 Xcode 工程：

```bash
./build.sh
./test.sh
```

本机 Swift 6.4 若报 SwiftUI 宏插件错误，用 `SWIFTFLAGS=-disable-sandbox ./build.sh` / `SWIFTFLAGS=-disable-sandbox ./test.sh`。界面改版后先 `./test.sh --approve` 重拍 `goldens/`，再跑一次 `./test.sh` 验证。

`build/` 生成通用 App 和 DMG；`build-test/summary.txt` 保存逻辑、界面与截图检查结果。截图先查看，再决定是否更新 `goldens/` 和 `docs/` 的介绍页截图；新增 `.swift` 文件要加进 `build.sh` 的 `SRC`。

第零期修改了助手共用的命令执行实现；从 2.6.2 升级时，可能需要在「登录项与扩展」中重新允许充电助手。

构建优先使用本机固定签名证书，没有时使用临时签名。`helper-cache/` 复用已签名的同一份充电助手，避免无必要的重新授权；证书、密码和助手缓存不提交仓库。
