# Mac 一键优化

**不用重启，也能让卡顿的 Mac 重新跟手。** · [介绍页](https://yostyang.github.io/mac-optimizer/)

## 为什么做这个

如果你和我一样，平时用 MacBook Pro 外接显示器，同时开着一堆 AI 工具、软件和浏览器窗口，那你可能也遇到过这种情况：电脑突然变卡，鼠标和键盘都不跟手了。可打开「活动监视器」一看，没有哪个软件特别占 CPU 或内存，也没有程序卡死。按理说，电脑应该运行得好好的。

遇到这种情况，重启当然最省事，但代价也最大：开着的窗口、跑着的任务、手头的工作状态，全都得重来。我就想，有没有办法不重启也能把问题解决掉？于是 vibe 出了这个小工具。

它会把这类“查不出原因”的卡顿背后常见的元凶找出来，比如卡住的 Spotlight 索引、同时运行的多个 VPN、后台虚拟机、开太多的浏览器、大屏幕的渲染负担，然后让你一键处理。

## 功能

- **智能体检**：给出健康分，列出发现的问题，选好要处理的项目后一键修复
- **实时概览**：CPU 负载、可用内存、连续运行天数，每 4 秒自动刷新
- **资源排行**：按应用汇总内存和 CPU 占用，可以直接退出
- **开机启动**：关掉不需要的开机自启应用
- **浏览器**：同时开着多个浏览器时，快速退出多余的
- **Spotlight**：索引进程卡住时一键重启，不会丢失任何数据
- **虚拟机**：找出 Claude 桌面版等应用的后台虚拟机占用
- **网络与 VPN**：检测多个 VPN 同时运行造成的冲突
- **显示性能**：根据系统版本，直接跳到 Liquid Glass、降低透明度、减弱动态效果的设置页，减轻外接大屏的渲染负担

所有操作都需要你手动选择或点击，不会自动关闭任何东西，不会删除你的文件，也不需要管理员密码。

## 安装

到 [Releases](../../releases) 下载最新的 `Mac-Optimizer-x.x.dmg`，打开后把 App 拖进「应用程序」。

应用没有经过苹果公证。第一次打开时如果提示“无法验证开发者”，请到 **系统设置 › 隐私与安全性**，在底部点「仍要打开」；也可以在终端运行：

```bash
xattr -dr com.apple.quarantine "/Applications/Mac一键优化.app"
```

支持 macOS 13 及以上版本，Apple 芯片和 Intel 芯片都可以用。

## 从源码构建

需要安装 Xcode 命令行工具：

```bash
./build.sh
```
