## 改动

| 项目 | 改动 |
|---|---|
| M01 菜单栏合并状态图标 | 「菜单栏显示内容」新增「合并状态」：Wi-Fi 信号、音量、电池合成一个图标。可设置显示哪几项、并排或紧凑（Wi-Fi 与音量上下叠放）、大小、电池里是否显示百分比、电池是否按电量着色。默认并排、中号、彩色电池。鼠标停留显示文字说明。 |
| M01 面板控制 | 选了「合并状态」时，面板里多一张卡片：音量滑块、静音按钮、Wi-Fi 信号强度。Wi-Fi 名称为可选项，打开时才申请定位权限。 |
| 拖动到分区更可靠（原 2.10.1） | ⇧ 松开后 0.3 秒内松鼠标仍算数；归位 0.25 秒后复查，位置被应用改回就再放一次（不改撤销位置）；尺寸受限的提示写明是窗口缩不到这么小。 |

数据来源：Wi-Fi 用 CoreWLAN，音量用 CoreAudio 并监听变化，不轮询、不需要新权限。思路参考开源项目 status-trio（Apache-2.0），代码独立实现。实现要点见 `HANDOFF.md`。

## 真机结果

- 2.11.0 原地安装后充电助手随新版本重启，设置恢复，没有授权提示。
- 「显示 Wi-Fi 名称」：用户打开后完成定位授权，面板显示「Seed · 信号中（-64 dBm）」；音量滑块读数与系统一致。
- 安装包：完整性校验通过；只读挂载后主程序与充电助手和构建逐字节一致；从安装包内复跑自检 804/0；充电助手 CDHash 与 2.9.2、2.10.0 相同（`72ee3688…`），升级不需要重新授权。SHA-256：`3b178b7356f5854cc73fa40fe90be61e217b7c458cb916356bf24ef1f9c9d05b`（构建提交 `c5194f4`）。
- 用户在菜单栏启用合并状态图标（并排、彩色，电量 84% 充电中显示为绿色），反馈没有问题；拖动到分区同版本试用后反馈没有问题。

## 已知不足与未验证

- 「紧凑」模式的叠放符号偏小，清晰度一般，作为可选项保留。
- 单色模式下显示百分比时没有充电标识。
- 没有电池的 Mac、不能调音量的输出设备（HDMI、部分显示器）、macOS 13/14 只有自动化测试，没有真机验证。
- 拖动失败的三种原因是推断，修复后用户反馈正常，但没有日志证明是哪一种在起作用。
- K3 Pro 电量：等待放电后的对照读数。
