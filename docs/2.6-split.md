## 2.6 · 桌面分区

**新功能**：为每块显示器选分区模板（1:2:1 三栏 / 左右平分 / 2/3 + 1/3，统一 8pt 间距），在 ⌘K 或 ⌥Space 命令面板里用「放到左区 / 中区 / 右区」把前台窗口放进当前屏幕的分区，「撤销归位」可一步还原。入口在「显示器」页右上角「桌面分区」，也在侧栏。

**行为约束**：只移动前台应用的焦点窗口；不激活其它应用、不移动其它窗口、不强退；移动后读回位置，区分「已归位 / 尺寸受应用限制 / 此窗口不可移动」。模板按显示器 UUID 保存，默认关闭，可随时「关闭分区」。没有新增默认全局快捷键。

**权限**：需要「辅助功能」权限（AXIsProcessTrusted）；未授权时分区命令不执行，页面显示「打开系统设置」引导。不申请输入监控。签名身份与 2.5 相同，已授权的用户升级后沿用。

**多屏**：NSScreen 可用区域换算到 AX 全局左上原点坐标，支持左侧/上方副屏的负坐标与混合缩放。

## 升级注意

- 充电助手源码未变、复用已签名助手；若「后台项目」里显示为未允许，请在「系统设置 › 通用 › 登录项与扩展」重新打开一次。
- 应用未公证，首次打开仍需在「隐私与安全性」点「仍要打开」。
