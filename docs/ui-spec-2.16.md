## 2. 颜色

所有取值定义在 `V25Design.swift`（`DS`）与 `main.swift`。文字与图形分开：文字用 `DS.text.*`，承载含义的图形用 `good / warn / bad / accent`。

| 用途 | 浅色 | 深色 |
|---|---|---|
| 窗口底 `DS.window` | #F2F2F5 | #16162A |
| 卡片 `DS.card` | #FFFFFF | #11121E |
| 抬起面 `DS.raised` | #FAFAFC | #26263E |
| 侧栏 `DS.sidebar` | #F6F6F9 | #131326 |
| 次级文字 `DS.text.secondary` | #62626E | #A1A1B0 |
| 正常文字 `DS.text.good` | #08744F | #34D399 |
| 注意文字 `DS.text.warn` | #8B5100 | #FFB340 |
| 危险文字 `DS.text.bad` | #B42318 | #FF6B6B |
| 选中行副字 `DS.text.onSelectionSecondary` | #EEECFB | #EEECFB |
| 承载白字的填充 `DS.selectionFill` | #5846D6 | #5846D6 |
| 状态图形 `good / warn / bad` | #0E9F6E / #B26A00 / #D93B3B | #34D399 / #FFB340 / #FF6B6B |

规则：

- 电量状态的唯一判断是 `BatteryLevel.of(percent)`：≤ 10% 危险、11–20% 注意、21% 正常（D2）。内置电池、蓝牙外设、单独菜单栏电池图标和合并图标都走这一处；图形用 `graphic`，文字用 `text`，AppKit 绘制用 `graphicNS`（`goodNS / warnNS / badNS`）。
- 正常电量不染成绿色；`DS.text.good` 只用于「正常 / 完成」这类状态文字。
- 状态图形色不能直接当文字色用；需要时用 `DS.text.tone(_:)` 换到对应文字色。
- 承载白字的填充（列表选中行、操作面板选中项、主按钮）用 `DS.selectionFill`；品牌紫 `accent` 只做图形、焦点和开关。
- 不允许在界面代码里写系统红/橙/绿或独立硬编码色（`Color.red`、`.orange`、`NSColor.systemRed` 等）。2.16 已把剩余的电量、告警、显示器提示改用 `bad / warn` 令牌。
- 非列表选择控件（`ChoiceChip`、分段控件）也纳入对比度检测，不能只替换字符串而不检查渲染结果。

## 3. 字号与内边距

- 语义样式：`DS.title` 17 / `DS.body` 13 / `DS.sub` 12 / `DS.cap` 12 / `DS.unit` 13 / `DS.label` 12.5 / `DS.eyebrow` 12 / `DS.num` 数字等宽。
- 说明文字不小于 12 pt；10–11 pt 只用于既定单位和时间，行尾注明 `// 单位`、`// 时间`；纯图标注明 `// 图标`。
- 页面文字不直接写 `.system(size:)`；图标、按容器计算的动态尺寸、令牌自身定义分别在行尾登记 `// 图标`、`// 动态`、`// 令牌`。`fontlint.sh` 守住这两条。
- 内边距：指标卡 `DS.cardPadding` 16；带标题的 `Card` 用 `DS.titledCardPadding` 16；面板指标卡、电池宽卡与紧凑 `Tile` 用 `DS.tilePadding` 10。
- 圆角只有三种：卡片 12、控件 6、胶囊 999。

## 4. 布局与滚动

- 最小主窗口 1080×720，保持可见滚动条约定；长名称中间截断，不用省略号挤掉数值。
- 页面写作 `PageScaffold { 摘要 } details: { 详情 }`：摘要必须完整可见、不滚动；只有详情可局部滚动。标了摘要区的页面按此检查，没标的仍要求整页放得下。
- 菜单栏面板指标卡高度固定 72 pt（标题行 / 数值与曲线同一行 / 一行说明）；面板默认内容 ≤ 810 pt，高度下限 420 pt，矮屏必须能滚。
- 键盘：Tab 到达操作；方向键选择或调整；Enter 执行；Esc 取消未提交输入或关闭浮层。可操作控件保留稳定的辅助功能标识和朗读标签。

## 5. 页面职责

- **概览**：回答「现在是否需要处理、主要原因、建议下一步」，不继续堆叠实时读数。
- **实时监控**：连续观察 CPU、内存、磁盘、网络和高占用进程；GPU、温度、风扇、电池等次要读数在详情区定位原因。
- **底栏**：表达当前对象与可执行操作，不重复整段页面健康状态。选中对象时左侧写「名称 · 类型」，右侧是该对象的主操作（具体动词）和「更多操作 ⌘K」；没有选中对象时回退到当前页面最多两个常驻动作；没有可执行动作就不放按钮。
- 侧栏分组：状态（概览、实时监控、电池）/ 日常控制（显示器、网络诊断、桌面分区）/ 整理与恢复（清理预览、开机启动、改动与提醒）/ 全部工具 / 设置。⌘1–9 依次为概览、实时监控、电池、显示器、网络诊断、桌面分区、清理预览、开机启动、改动与提醒。

## 6. 状态与读数

- 加载、无数据、未知、过期、失败、完成统一用 `StateLine`，文案给出当前状态和可执行的下一步；`statelint.sh` 检查列出的页面。
- 外设读数四态：**有效**显示百分比；**缓存**表示这次没读到、显示最近成功值；**过期**表示缓存超过有效窗口，主值显示「— · 已过期」；**未取得 / 断连**显示「— · 未取得 · 查看原因」。未知不等于 0%，也不用过期值伪报低电量。
- 缓存有效窗口 = 刷新间隔 × 2（当前 5 分钟 → 10 分钟）。逐设备分别记录 `lastAttemptAt`、`lastSuccessAt`、`source`；来源没给上报时间时 `sourceReportedAt` 保持未知，只写「读取于」。
- 原因至少区分未连接、未授权、不支持当前读取路径、读取失败、未取得有效上报；每种给刷新、打开对应系统设置或说明入口。原因入口可用鼠标和键盘打开，不能只放在悬停提示里。
- 低电量不只靠颜色：图标形状不同（三角 / 圆形），旁边有「电量极低 / 电量低」文字，朗读包含设备名、有效数值和状态。通知阈值是独立设置，关掉通知不影响视觉状态。
- 提醒关闭时只显示总开关和一句说明，阈值、充满、插拔、异常耗电、全屏与外设提醒选项隐藏而不是置灰占位；开关和折叠不重置已有配置。已开启但系统不允许通知时说明权限状态并给设置入口，不显示「已生效」。
- 对比度等验收的「未验收」表示证据不足，不等于通过，也不等于产品故障。

## 7. 对比度验收（N1）

- 文字区域来自 `.contrastTarget(id, role)` 铺设的透明布局标记（真实 `NSView`，不接收点击、辅助功能忽略），不读辅助功能树。`.contrastTarget` 只在 `MOTests.active` 时插入，发布版零开销。
- 取样在真实渲染位图里进行：区域内出现最多的亮度档作为实际背景（含透明叠加、选中底、卡片色），离背景最远的墨迹像素 90 分位作为前景。
- 口径固定：普通文字 ≥ 4.5:1；大字（≥ 18 pt，或 ≥ 14 pt 且 semibold 以上）≥ 3:1；承载含义的图形 ≥ 3:1。执行测试时不能按结果调整口径。
- 每个必测用例必须有 `passed / failed / unverified` 三态之一。缺少文字区域、截图失败、只测到部分必测目标都记为 `unverified`，附原因与目标标识；`measuredRatio` 为空，不写 0。
- 报告写入 `build-test/shots/contrast-report.json` 与 `contrast-summary.txt`；`test.sh` 只在「通过数 > 0、失败 0、未验收 0」时输出「全部验收通过」，否则不放行。
- 辅助功能树仍用于键盘、朗读和操作测试；本项只移除对比度检测对它的依赖。截图阶段另有一个 AX 不可用 + 故意缺目标的探针，必须得到 `unverified` 且已有文字仍能测出数值。

## 8. 分区（N9）

- 沿用 2–4 栏、宽度百分比（合计 100%，单栏 ≥ 10%）、竖线拖动、← → 每次 5%、⇧ 1%。上下拆分的栏新增可拖动横线、↑ ↓ 每次 5%、⇧ 1% 和上方百分比输入。
- 上下子区各至少 20%，默认 50 / 50（D4）；拖动吸附 5%，按住 ⌥ 不吸附；拖动只在松手后提交，Esc 取消未提交值；非法数字、非整数、越界拒绝提交并说明可用范围。
- 前置为已选中且仍连接的显示器；比例编辑与「恢复默认」只在自定义布局已启用时出现，查看页面不会自动启用布局。
- 「恢复默认比例」只把当前屏幕恢复为两栏 50 / 50、关闭上下拆分，仍保持自定义布局启用；保留全局间距和其他屏幕配置，不移动任何现有窗口（D5）。
- 偏好写入 `split.layout.v2`（`schemaVersion`、`displayID`、`columnPercents`、`rowPercentsByColumn`）。旧键 `split.customPct`、`split.custom`、`split.customRows` 不立即删除：旧的上下平分迁为 50 / 50，新比例只写 v2。回退旧版时旧版只能看到它能表达的栏宽与是否平分。
- 归位命令的名称、缩略图与实际落区来自同一份布局：名称优先「右侧 1/3」「左侧上方」，复杂比例用「右侧 30%」，同名补区号；命令生成后布局或屏幕变化，不执行旧区域；窗口最小尺寸受限时明确说明没有完全到位。

## 9. 记录完整浏览（N8）

- 「改动与提醒」的清理记录卡保留最近摘要，提供「查看全部」，完整视图同时包含现存清理记录与卸载记录，按类型区分，默认时间倒序、按本地日期分组；可返回原页面。
- 每项显示时间、名称、原路径、记录类型和恢复状态；只有能恢复才显示有效按钮。恢复中同一项禁用重复操作，成功后原地更新。
- 文件已不在、同名冲突、目标目录变化或写入失败沿用既有安全行为（不覆盖同名、改名放回、原目录消失会重建）并说明结果。不新增清空历史、批量恢复或新的保留策略；「全部」指仍持久化存在的记录。
- 历史视图按需渲染，1000 条固定样例不得造成明显界面阻塞；不触发重新扫描，也不改变固定清理底栏和移到废纸篓流程。

## 10. 测试门槛

| 检查 | 入口 | 门槛 |
|---|---|---|
| 逻辑自检 | `--selftest` | 0 失败；含 N1 取样与判定、N2–N5、N8–N10 的纯逻辑 |
| 界面交互 | `--uitest` | 0 失败；含 N4 折叠、N8 查看全部、N10 底栏选中 |
| 截图与黄金图 | `--snapshot` | 0 失败；必测截图齐全；黄金图差异需先说明变更点再 `--approve` 重拍并复测 |
| 对比度 | `--snapshot` → `contrast: N 通过, 0 失败, 0 未验收` | 必测项无失败、无未验收 |
| 字号 | `./fontlint.sh` | 0 失败 |
| 状态 | `./statelint.sh` | 0 失败 |

`./test.sh` 汇总以上全部检查；`SWIFTFLAGS=-disable-sandbox` 供受限沙盒编译。缺截图、对比度未验收、界面或自检失败都返回非 0。发布前按 PRD §5.2 再核对版本、双架构、签名、正式包不含测试入口与下载哈希。
