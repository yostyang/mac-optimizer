# 第零期：安全与稳定

日期：2026-11-06。基于 `v2.6.2`（发布标签 commit `2b00a27`），按用户 HTML 改版方案的第零期实施。

## 改动

- 登录项删除不再拼接 bash/AppleScript 字符串；固定 AppleScript 通过 `argv` 接收完整名称。读取使用 JSON，名称里的引号、分号、逗号和换行保持完整；回读失败不能算作移除成功。
- 通用命令入口统一为 `ProcessRunner.run(path, args, timeout:)`，所有原 `sh()` 调用迁移到可执行文件路径与参数数组；内存百分比在 Swift 内解析。App 与 DNS 助手的 `RealRunner` 共用该实现。
- stdout/stderr 使用非阻塞读取并交替排空。每路保留最多 1 MiB，超过后继续排空并标记截断；默认 10 秒期限，先 TERM，必要时 KILL 本次创建的子进程。stdin 为 `/dev/null`，启动失败、非零状态、超时均有明确结果。不向用户应用或进程组执行超时回收。
- 多 VPN 提示列出所有候选，默认全部不勾选；VPN 控制台建议同样默认不选，不再因名称含 Lets 而默认退出。
- 工具页 `Row.verify` 接入 `OperationCheck`。退出类核验原应用/进程实际终止，登录项核验指定名称已消失；后台执行可能阻塞的回读，主线程更新结果。重复提交被阻止，仅核验成功增加优化次数。系统设置跳转等无核验动作只报告已发起，不增加统计。

未涉及后续界面改版、个人规则表、SwiftPM、全项目并发迁移或新增分屏能力。

## 构建影响

`DNSCore.swift` 由特权助手共用，因此助手源码哈希与二进制会变化；以后安装这一改动时可能需要按系统提示重新允许助手。测试确认固定签名要求和固定系统命令约束仍通过。本期未改变 SMC 充电控制逻辑、真实 DNS 或用户登录项。
