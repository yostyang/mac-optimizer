# 第一期：规范与实时监控

按用户提供的 HTML 改版方案实施，基于第零期提交 `5ae4fef`。

## 行为

- 实时监控采用三层指标卡：标题与状态、大数字与曲线、两行二级信息。默认 3×3，最小高度采用 3×2 加磁盘/风扇/电池紧凑行。
- 统一字号、12 pt 卡片圆角、16 pt 内边距和 12 pt 间距；七类指标有独立浅/深配色。指标色与正常/注意/危险状态色分开，深色卡片比页面深。
- 新增 MetricTile、SubStats、KPIStrip、StatusPill、BarList、InlineSegment、Footnote；缺失读数显示破折号和原因。温度、核心、负载、交换空间等来自已有读数，不虚构历史峰值和持续时间。
- 登录启动、菜单栏、常亮和接显示器模式集中在设置；实时监控顶栏可打开原快捷操作，开启状态用胶囊显示。
- 页面与工具路由改用 Page/ToolKind；通知使用稳定页面名并兼容旧通知。导航按键使用具名键码。
- 进程 CPU 的 30% / 80% 阈值与 Diagnosis 共用常量。监控仍为前台 2 秒、后台 5 秒，未新增采样定时器。

## 验收流程修复

后台向自身发起 AX 预查询会在当前 macOS 上与 SwiftUI view-graph 锁互相等待。已移除此可选预查询，仍由主线程查询真实辅助功能树，保留窗口就绪和所有控件断言。输出改为即时刷新，便于定位等待。

测试可以复用签名包，但必须同时核对源码、构建参数、两个二进制哈希和签名；任何不一致都会重建。界面测试通过 Launch Services 前台启动，并检查完整的零失败汇总，避免只依据 open 的退出码误报通过。
