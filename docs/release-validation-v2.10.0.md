## 改动

| 项目 | 改动 |
|---|---|
| S02 自定义分区比例 | 每块屏幕可在三种固定模板之外设 2–4 栏的自定义比例（每栏权重 1–9），加减号调整并实时预览；与固定模板二选一，老用户已选的模板不变。四栏时左区 = 第一栏、右区 = 最后一栏，中间两栏在 ⌘K 里是「放到第 2 区」「放到第 3 区」。 |
| S02 上下平分 | 自定义模板里每一栏可以再上下平分（例如四栏里中间两栏各分上下，共 6 个区）。区按从左到右、每栏从上到下编号；左/中/右仍按栏算，指该栏上面的区，其余的区在 ⌘K 里按序号给出。 |
| S02 分区间距 | 窗口之间和屏幕边缘的留空可调，0–24 pt，步长 2，默认 8，所有屏幕共用；归位、拖动高亮和预览都用同一个值。 |
| S02 拖动到分区 | 桌面分区页新增开关「按住 ⇧ 拖动窗口时显示分区」，默认关闭。按住 ⇧ 拖标题栏时显示当前模板的分区高亮，在某个区里松手即归位；松手前放开 ⇧ 取消；可用「撤销归位」回到拖动前的位置。不碰屏幕边缘，不与 macOS 15 起的系统平铺冲突。 |
| C01 清理记录恢复 | 清理页操作记录里，仍在废纸篓的项显示「恢复」。原位置有同名文件时不覆盖，改名为「名称（恢复）」放回；原目录不存在会重建；废纸篓已清倒、旧版记录没有废纸篓位置时分别说明。恢复结果写入改动记录。 |
| K02 Keychron 键盘电量 | Keychron K3 系列通过蓝牙 HID 的 3 号报告自报电量（[1] = 百分比，[2...7] = 蓝牙地址），系统不显示。设备电量卡片在有读不到电量的 Keychron 键盘时给出「读取 Keychron 电量」，用户授权「输入监控」后读取；报告里的地址与已连接的配对设备对得上才显示，来源标为「键盘自报电量（HID）」。只取这一个报告，不监听按键。`--read-keychron-battery` 可打印原始报告用于排查。K3 Pro 已在真机读到地址匹配的报告；数值准确性及其他型号仍待验证。 |
| 充电助手 | 直接从安装包（`/Volumes`）或系统隔离位置运行时，不自动重新注册充电助手，避免把助手注册到随时会消失的位置。 |

实现要点见 `HANDOFF.md` 的 2.10 一节。

## 拖动到分区的可行性验证（真机，macOS 27.2）

- 不需要新增权限：全局鼠标监听加现有的辅助功能权限即可。
- 第一轮：判断条件要求窗口位移与鼠标位移相差不超过 12 pt、最多 4 次机会，Chrome 约一半失败、Edge 多数失败、Claude 全部失败。原因是窗口位置读数比鼠标慢一拍。
- 第二轮：改为「窗口动了且方向与鼠标一致」，鼠标走出 200 pt 窗口仍不动才放弃。Chrome、Edge、访达、Claude 均能识别并归位；选文字、拖文件被正确排除。
- 开销：约 2800 个鼠标事件累计处理不到 1 秒；不按 ⇧ 时不做任何辅助功能查询。
- 未覆盖：微信（已加按窗口列表查找的后备路径，未真机验证）、跨屏拖动、macOS 13/14。
