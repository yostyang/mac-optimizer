# 2.3：电池读数与显示器色彩控制

电池实时输入原来固定为空，显示器设置先改变界面再发送硬件请求，软件色温会影响所有屏幕。本版接通数据来源，并把显示器修改改成可回读、可恢复的独立操作。

## 本轮实现

- 电池从单次 AppleSmartBattery 快照读取电压、带符号电流、实时 DC 输入，使用公开 IOPS 与 SmartBattery 适配器信息做后备。拔电清除旧输入；电源切换短暂等待遥测稳定。系统功耗按输入与电池贡献估算，缺字段或不一致时不拼数。
- 区分接电充电、停充、已充满、电池供电、接电补充放电。界面区分实时输入、适配器上报功率和系统估算，并显示来源与更新时间。未读到健康状态时不再默认为正常。
- 显示器提供“显示设置”和“色彩模式”标签。ICC 列表优先使用当前屏幕注册的描述文件，并允许用户安装的显示器类 profile；不将其他屏幕自动生成的 profile 混入列表。
- ICC 修改后核对配置，保存本次修改前的描述文件，提供恢复入口；恢复以实际原文件为准，避免误清除已有自定义配置。比较时识别系统规范化及符号链接路径。
- DDC 通过只读 EDID 与 CoreGraphics 的厂商、型号及序列匹配。多屏身份不明确时不猜测通道；按屏幕保存 Gamma、色温和定时设置。
- 硬件色彩预设和显示模式只列设备声明的值，未知显示模式保留编号，不擅自命名为 P3 或观影。修改后回读，失败或无法确认时保留明确状态；可恢复修改前的硬件色彩值。
- DDC 写入按“屏幕+功能”合并请求，串行执行并核对结果；旧请求、刷新或重连后的迟到结果不覆盖当前状态。输入切换无法回读时明确标为未确认。
- Gamma 保存目标屏幕原来的传递表，调整时保留原曲线，关闭时只恢复目标屏幕。
- 外设增加独立短进程的经典蓝牙读取，并扩展只读 IORegistry 搜索。经典蓝牙无效0值保留未知；同名设备没有地址佐证时不猜测归属。不开启持续扫描，不刷固件。
- 电量提醒关闭时收起无效提示音控件，保留明确说明；外设未知状态与刷新时间压缩成一行，适配小窗口。

## 验证与边界

新增测试覆盖供电状态组合、无符号补码电流、旧字段清除、过期值、两屏同时操作、失败写入、回读不符、硬件色彩恢复、ICC 原配置恢复及同名外设。

界面流程使用模拟硬件点击真实入口，截图覆盖浅色、深色和最小窗口。真实硬件诊断通过 `--read-capabilities` 只读执行。ICC 实机写入/恢复验证使用当前文件的同色彩数据副本，随后恢复原配置。

需要在具体设备继续确认的行为：物理插拔、真实充电/放电切换、不同硬件色彩预设的视觉效果、双外屏实体连接。模拟测试通过不能代替这些物理验证。经典蓝牙读取扩展不能保证所有 Keychron 型号/固件都提供有效电量；没有读数时仍显示未知。

本轮未改充电助手或 DNS 助手代码，未加入屏幕/外设分项功耗推算、厂商 M-book/iDevice 模拟、完整应用卸载或真实按应用网络字节统计。2.3（19）为正式发布版。

## 技术资料

- [Apple ColorSync 设备 profile API](https://developer.apple.com/documentation/colorsync/colorsyncdevicesetcustomprofiles(_:_:_:)) 与本机 SDK 头文件。
- [Stats 电池读取](https://github.com/exelban/stats)、[PowerTop](https://github.com/scavin/PowerTop)：电池来源与供电状态参考，MIT。
- [Keychron Battery](https://github.com/rxrdev/keychron-battery-level)：经典蓝牙短进程读取与 IORegistry 路径参考，MIT。
- [MonitorControl](https://github.com/MonitorControl/MonitorControl)：多屏身份与 DDC 路径参考，MIT。
- [IOAVService 私有接口声明](https://gist.github.com/zhuowei/223e449a90a32eefd2c3244e252818d1)：只读 EDID 接口签名参考。运行时检查符号和 EDID 完整性，接口不可用时降级。

## 发布包验收结果

2.3（19）：自检 392、界面流程 95、截图检查 80，全部 0 失败；最终 DMG 只读挂载后的包内自检 392 通过。通用架构、签名与 DMG 完整性检查通过，助手二进制保持一致。53 张截图中 32 张必需截图齐全，人工查看 7 张变更关键页，未更新黄金图。

这些检查不替代上述尚未覆盖的物理设备组合。安装包没有自动替换已安装应用。
