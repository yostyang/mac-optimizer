## 2.6.2 · 小修：空搜索 ⌘K 与撤销归位

**修复**
- 空搜索按 ⌘K 不再静默无反应：在「桌面分区」页弹出「放到左区 / 中区 / 右区」「撤销归位」四个操作；其它页显示提示「在顶部搜索框输入关键词…选中后按 ⌘K 查看更多操作」。
- 「撤销归位」绑定到当初被移动的那个具体窗口：同一应用（如浏览器）开两个窗口时不会撤错；原窗口已关闭时明确提示并清除撤销记录，不移动其它窗口。
- 所有结果与失败都有可见提示（主窗口 Toast，或屏幕底部不抢焦点的浮层）。

**本版不包含**：全局分区快捷键设置、拖拽落区、默认归区、工作模式。分屏快捷键可继续使用 Rectangle 等工具。

**测试工程改动**（不影响 App 功能）
- UI 测试增加诊断日志（测试进程、前台、窗口状态、辅助功能树节点数、权限与屏幕状态）和 `build-test/env.log` 环境记录。
- 主窗口测试放回屏幕内；找控件前做「测试窗口就绪」检查（活动应用、活动窗口、未遮挡、辅助功能树非空），不满足直接判失败并写明原因。
- 测试等待改为分发 AppKit 事件（`MO_TEST_PLAIN_RUNLOOP=1` 可回退）。
- 就绪检查前用 AX API 从后台线程只读查询一次本进程，触发 SwiftUI 生成辅助功能树（`MO_TEST_NO_AX_PRIME=1` 可关闭）。这解决了安装前复测时 UI 测试偶发大面积失败的问题。
