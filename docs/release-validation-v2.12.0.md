## 改动（《视觉与交互优化方案》P0 可读性）

| 项目 | 改动 |
|---|---|
| 文字承载色 | `DS.text.secondary / good / warn / bad / onSelection / onSelectionSecondary`，与品牌色、状态图形色、指标色分开。浅色次级 `#62626E`、正常 `#08744F`、注意 `#8B5100`、危险 `#B42318`；深色次级 `#A1A1B0`，状态文字沿用原值。 |
| 选中态 | 列表、⌘K 操作面板、进程选中行与主按钮底色 `DS.selectionFill` = `#5846D6`，主字白、副字 `#EEECFB`。 |
| 菜单栏电池 | 显示百分比时充电也画闪电（单色、彩色），放不下时数字缩小；`TrioIcon.batteryMarks` 是唯一判断入口。静音斜杠回归通过。 |
| 卡片内边距 | `DS.tilePadding`（10）用于面板指标卡、电池宽卡、合并状态卡、Tile；带标题 `Card` 用 `DS.titledCardPadding`（12）。改成 16 时 `fits` 报电池页最小窗口浅/深色超出 28 pt，故保留 12，统一并入 2.13。 |
