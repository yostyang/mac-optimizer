6 条设计原则

大数字配小单位

数值约 30pt，单位 13pt、灰色。数字就是视觉中心，不用渐变和彩色方块来撑场面。

每张卡片三层

标签行（左边名称，右边补充信息，如「均温 68°C」），中间是大数字和图表，底部 2～4 行二级数据。

颜色只用来表示数据

每类指标固定一个色相，只用在标签文字和图表上。卡片和背景保持中性。状态色单独一套，只在超过阈值时出现。

图表是卡片的一部分

曲线横跨整张卡片，带淡色面积和末端圆点；不再是缩在中间的小迷你图。

主数字下面放子数据

例如延迟卡片里大字是「28 ms」，下面用竖线分隔开「路由器 / DNS / 代理」三个小指标。

说清数据来源

「1 分钟负载（非百分比）」「仅读取」「状态来自 macOS 热压力」，页面底部再加一行采样频率和单位说明。这是你们已有的长处，把它固定成组件。

注意事项

不照搬参考图

不用参考图 1 的暖色背景，也不用参考图 2 那款产品的配色和标志。只借鉴卡片结构、字号层级和数据表达，品牌紫保留。

颜色别太花

7 个指标色加 3 个状态色容易显得花。指标色只用在标签文字和图表线上，不做大面积填充。

性能

整卡宽曲线和 3×3 网格会让重绘面积更大。曲线继续复用 Monitor 已有的历史数据，不新增定时器；第二期用 measure.sh 实测。
