为什么做这个

如果你和我一样，平时用 MacBook Pro 外接显示器，同时开着一堆 AI 工具、软件和浏览器窗口，那你可能也遇到过这种情况：电脑突然变卡，鼠标和键盘都不跟手了。

可打开「活动监视器」一看，没有哪个软件特别占 CPU 或内存，也没有程序卡死。按理说，电脑应该运行得好好的。

重启当然最省事，但代价也最大。

开着的窗口、跑着的任务、手头的工作状态，全都得重来。我就想，有没有办法不重启也能把问题解决掉？于是 vibe 出了这个小工具。

智能体检

几秒钟给出健康分，列出问题，选好要处理的项目后一键修复。

◔

实时概览

CPU 负载、可用内存、连续运行天数，每 4 秒自动刷新。

⌕

Spotlight 索引卡住

索引进程偷偷占满 CPU 是常见元凶，一键重启它，不会丢任何数据。

⇅

多个 VPN 冲突

两个 VPN 同时运行会互相抢网络，视频卡、网页慢，帮你只留一个。

▣

后台虚拟机

找出 Claude 桌面版等 AI 应用在后台跑的虚拟机，看看它吃了多少资源。

◍

浏览器太多

Chrome、Edge、豆包、夸克同时开？看清每个占多少内存，一键退出多余的。

▭

外接大屏渲染负担

按系统版本直达 Liquid Glass、降低透明度、减弱动态效果的设置，减轻 5K 带鱼屏的压力。

⏻

开机启动与资源排行

关掉不需要的开机自启，按应用汇总内存和 CPU，谁最占资源一目了然。

放心用

  • 不会自动动手每一项操作都要你自己选、自己点。
  • 不删任何文件只是退出程序或重启系统服务。
  • 不要管理员密码不装后台常驻服务，不改系统文件。
  • 完全开源代码都在 GitHub 上，随时可以查看。

安装

  1. 到 下载页 下载最新的 Mac-Optimizer-x.x.dmg。
  2. 打开 DMG，把「Mac一键优化」拖进「应用程序」。
  3. 应用没有经过苹果公证，第一次打开如果提示“无法验证开发者”，到 系统设置 › 隐私与安全性，在底部点「仍要打开」。也可以在终端运行：
    xattr -dr com.apple.quarantine "/Applications/Mac一键优化.app"

下次卡顿，先别急着重启
