# 清理、卸载、DNS 与发布回滚修复

日期：2026-11-13。基于 `0145411`，分支 `codex/fix-safety-review`。

## 修复内容

- 卸载先校验 Bundle ID；残留路径必须严格位于指定根目录内，拒绝根目录、路径穿越和符号链接越界。移动前再次校验，用户 `Library` 根加入保护。
- 白名单同时保护路径自身、子项及包含受保护项的父目录。整目录清理与卸载都不能带走白名单子目录。
- DNS 读取区分手动配置、DHCP 和读取失败；读取失败、备份损坏或备份不可保存时不修改 DNS。
- DNS 恢复逐项写入并回读，停用、缺失或失败的服务保留待恢复备份；全部恢复后才删除备份。
- 普通缓存和日志文件按文件大小统计。目录遍历接收取消信号；取消后不继续扫描安装包和 DerivedData。
- 发布用 `EXIT` 清理，在提交前失败或被终止时恢复脚本入口的完整 `Info.plist`；提交后推送失败不回滚已提交版本。

路径、模型和扫描纯逻辑提取到 `CleanCore.swift`，以便在 CI 中直接编译测试。此次没有进行目录结构迁移。
